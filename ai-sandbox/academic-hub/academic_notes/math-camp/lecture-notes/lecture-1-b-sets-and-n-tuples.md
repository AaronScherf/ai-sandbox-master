Let's continue from where we left off and explore some examples of functions to better understand the concepts of image, pre-image, onto, and 1-to-1 functions.

### Example 1: Function F1
Let's consider a simple example where \( X = \{U, C, M\} \) and \( Y = \{N, S\} \), and the function \( F1 \) is defined as:
- \( F1(U) = N \)
- \( F1(C) = N \)
- \( F1(M) = N \)

1. **Image of a set:**
   - \( S = \{N\} \)
   - \( F1(S) = \{N\} \)
   - \( F1(\{N\}) = \{N\} \)

2. **Pre-image of a set:**
   - Pre-image of \( N \) under \( F1 \):
     - \( F1^{-1}(N) = \{U, C, M\} \)

3. **Properties:**
   - **Onto:** The function \( F1 \) is not onto because the element \( S \) in \( Y \) is not hit by any element in \( X \).
   - **1-to-1:** The function \( F1 \) is not 1-to-1 because multiple elements in \( X \) map to the same element in \( Y \).

### Example 2: Function F2
Now, consider a different function \( F2 \) defined on the same domain \( X = \{U, C, M\} \) and range \( Y = \{N, S\} \), but with a different mapping:
- \( F2(U) = N \)
- \( F2(C) = S \)
- \( F2(M) = N \)

1. **Image of a set:**
   - \( S = \{N\} \)
   - \( F2(S) = \{N, S\} \)
   - \( F2(\{N\}) = \{N, S\} \)

2. **Pre-image of a set:**
   - Pre-image of \( N \) under \( F2 \):
     - \( F2^{-1}(N) = \{U, M\} \)
   - Pre-image of \( S \) under \( F2 \):
     - \( F2^{-1}(S) = \{C\} \)

3. **Properties:**
   - **Onto:** The function \( F2 \) is onto because every element in \( Y \) is hit by some element in \( X \).
   - **1-to-1:** The function \( F2 \) is not 1-to-1 because multiple elements in \( X \) map to the same element in \( Y \).
