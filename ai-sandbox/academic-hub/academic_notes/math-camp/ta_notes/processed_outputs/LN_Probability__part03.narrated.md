4 Conditional Expectation and Information. Sources. Williams gives the cleanest concise development of conditional expectation as a random variable measurable with respect to an information set. Klenke supplies the measure-theoretic existence theory; Hansen provides the econometric interpretation through prediction, projection, and conditional moments.

4.1 Elementary conditional expectation. Here's the passage rewritten for audio narration: If the random variable X is discrete, then the expected value of Y, given that X equals a specific value x, is defined as the sum, over all possible values of y, of y multiplied by the conditional probability that Y equals y, given that X equals x. Alternatively, if the pair of random variables X and Y has a joint probability density function, then the expected value of Y, given that X equals x, is defined as the integral, with respect to y, of y multiplied by the conditional probability density function of Y given X equals x, evaluated at y. In both of these cases, the conditional mean is a function of the specific value x. If we then evaluate this function at the random variable X itself, we obtain another random variable. This new random variable is denoted as m of X, and it is equal to the expected value of Y, given the random variable X.

4.2 Conditioning on a sigma-algebra. Here's the passage rewritten for natural spoken prose and audio narration: A sigma-algebra, denoted G, which is a subset of F, represents information. A random variable Z is G-measurable when its value can be determined from that information. Definition 4.1: Conditional Expectation Let Y be an integrable random variable, and let G be a sub-sigma-algebra of F. A random variable Z is a version of the conditional expectation of Y given G if: 1. First, Z is G-measurable. 2. Second, for every set G belonging to the sigma-algebra G, the integral of Z over the set G, with respect to the probability measure P, is equal to the integral of Y over G, with respect to the probability measure. The first condition says the conditional expectation uses only the available information. The second says it preserves averages on every event that can be distinguished using that information. Remark 4.2: A Rigorous Layer on Existence and Uniqueness If Y is in L-one, then the conditional expectation of Y given G exists and is unique almost surely. Its existence is an application of the Radon-Nikodym theorem to the signed measure, which is defined as nu of G equals the integral of Y over the set G, with respect to the probability measure P, for any set G belonging to the sigma-algebra G. For a math camp setting, the Radon-Nikodym theorem itself can be stated rather than proved. The important point is that conditional expectation is not merely notation based on a conditional density; it exists far more generally. When the sigma-algebra G is equal to the sigma-algebra generated by a random variable X, the Doob-Dynkin theorem implies that the conditional expectation of Y given the sigma-algebra generated by X is equal to m of X, for some measurable function m. This is the rigorous content of the conditional expectation of Y given X. Example 4.3: Conditioning on a Finite Partition Suppose G is generated by a finite partition of sets, A sub one through A sub m, where the probability of each A sub j is greater than zero. Then, the conditional expectation of Y given G is equal to the sum from j equals one to m of the conditional expectation of Y given A sub j, multiplied by the indicator function of A sub j. The conditional expectation is constant on each information cell. This is the simplest concrete model of "conditioning on information."

4.3 Core properties. Provided the expressions are integrable, the following properties hold: First, the expected value of 'a times X plus b times Y', conditional on G, equals 'a' times the expected value of X conditional on G, plus 'b' times the expected value of Y conditional on G. Second, if X is less than or equal to Y, then the expected value of X conditional on G is less than or equal to the expected value of Y conditional on G. Third, if X is G-measurable, then the expected value of X conditional on G equals X. Fourth, if Z is G-measurable, then the expected value of the product 'Z times X', conditional on G, equals Z times the expected value of X conditional on G. Fifth, the expected value of the expected value of X conditional on G, equals the expected value of X. Now, regarding the tower property: If H is a subset of G, and G is a subset of F, then the tower property states that the expected value of the expected value of X conditional on G, all conditional on H, equals the expected value of X conditional on H. In a more familiar notation, the expected value of the expected value of Y conditional on X and Z, all conditional on X, equals the expected value of Y conditional on X. Finally, if X is independent of G, then the expected value of X conditional on G equals the expected value of X, almost surely.

4.4 Conditional expectation as an L^2 projection. Suppose we have a random variable Y that belongs to the space of square-integrable random variables, which we denote as L-two. Now, consider a closed subspace, which we call L-two of script G. This space is defined as the set of all random variables Z such that Z is an element of L-two, and Z is measurable with respect to the sigma-algebra script G. Then, the conditional expectation of Y given script G represents the orthogonal projection of Y onto the subspace L-two of script G. In particular, this means that the expectation of the product of two terms—first, the difference between Y and the conditional expectation of Y given script G, and second, Z—is equal to zero. This holds true for all random variables Z that are elements of L-two of script G. Therefore, the conditional expectation of Y given script G is the specific value Z within L-two of script G that minimizes the expectation of the squared difference between Y and Z. Let's look at Example 4.4, titled "Conditional mean and regression error." Let's define a function, m of X, as the conditional expectation of Y given X. We also define a variable u as Y minus m of X. Then, the conditional expectation of u given X is equal to zero. Hence, for every square-integrable function h of X, the expectation of the product of u and h of X is equal to zero. This result is much stronger than simply stating that the expectation of the product of u and X is equal to zero. It means that the conditional-mean residual, which is u, is orthogonal to every square-integrable transformation of the conditioning variables.

4.5 Best prediction and Gaussian conditioning. The projection result states that among all measurable predictors based on X, the conditional mean, denoted as m of X, which is defined as the expected value of Y given X, minimizes mean squared prediction error. This means the expected value of the square of the difference between Y and m of X is less than or equal to the expected value of the square of the difference between Y and any other square-integrable function g of X. Now, consider jointly Gaussian variables. If the column vector containing Y and X is distributed as a multivariate normal distribution, with a mean vector whose components are mu sub Y and mu sub X, and a two-by-two covariance matrix where the top row contains sigma sub Y Y and sigma sub Y X, and the bottom row contains sigma sub X Y and sigma sub X X, then the conditional distribution is again Gaussian. Specifically, Y given that X equals little x, is distributed as a normal distribution. Its mean is equal to mu sub Y plus sigma sub Y X times the inverse of sigma sub X X, all multiplied by the quantity little x minus mu sub X. Its variance is equal to sigma sub Y Y minus sigma sub Y X times the inverse of sigma sub X X, all multiplied by sigma sub X Y. Thus, for jointly Gaussian vectors, the conditional expectation is linear in little x.

4.6 Conditional distributions as random probability measures. Here's the passage rewritten for natural spoken prose and audio narration: For discrete variables, the process of conditioning on the event where a random variable, let's call it X, takes on a specific value, little x, is quite straightforward. However, in continuous models, the event that the random variable X is exactly equal to that specific value, little x, typically has a probability of zero. This means we cannot literally use the standard ratio definition of conditional probability. Instead, a conditional density function, often written as 'f of Y given X', where the random variable Y takes the value 'little y' and the random variable X takes the value 'little x', should be understood as a version of what's called a regular conditional distribution . This means two things: First, for every specific value 'little x' that the variable X can take, this density function represents a valid probability law for the variable Y, in terms of 'little y'. Second, for any measurable set, let's call it A, the mapping from a value 'little x' to the probability of the random variable Y being in set A, given that the random variable X equals 'little x' – this entire mapping must be measurable and must satisfy a specific averaging identity. Remark four point five — Rigorous layer: Existence caveat These regular conditional distributions do exist on what are known as standard Borel spaces. These are the types of spaces used in essentially all conventional economic applications, and they include familiar examples like Euclidean spaces and spaces with a countable number of states. However, it's important to note that they are not guaranteed to exist on completely arbitrary measurable spaces. This is one of the reasons why probability theory often focuses on working with these well-behaved state spaces, rather than trying to achieve maximal generality across all possible types of spaces.

4.7 A change-of-measure viewpoint. If Q is another probability measure that is absolutely continuous with respect to P—meaning that any event with zero probability under P also has zero probability under Q—then the Radon–Nikodym theorem provides a nonnegative random variable. We call this variable L. It is defined as the Radon–Nikodym derivative of Q with respect to P, acting as a density function or likelihood ratio that connects the two measures. With this L, the probability of any event A under measure Q is equal to the expected value, calculated under measure P, of the product of L and the indicator function for A. The indicator function for A is a variable that takes the value one if event A occurs, and zero otherwise. Consequently, for any integrable random variable X, its expected value under measure Q is equal to the expected value, under measure P, of the product of L and X. This same mathematical device is fundamental to various applications, including likelihood ratios, importance sampling, Bayesian updating, and asset-pricing changes of measure.

4.8 Conditional variance and variance decomposition. Let's define the variance of Y, conditional on G. This is equal to the expected value, given G, of the quantity Y minus its expected value given G, all squared. Then, the total variance of Y is given by the expected value of the conditional variance of Y given G, plus the variance of the expected value of Y given G. The first term in this sum represents the average residual uncertainty, while the second term represents the variation in the predictable conditional means. A related principle, the law of total covariance, states that the total covariance between Y and Z is equal to the expected value of the conditional covariance between Y and Z given G, plus the covariance between the expected value of Y given G and the expected value of Z given G.

5 Common Distributions, Transformations, and Transforms. Sources. The distributional calculations draw on Blitzstein–Hwang and Bertsekas–Tsitsiklis, while Hansen is used to emphasize the families and transforms most useful in econometrics.

5.1 Discrete families. Here is the passage rewritten for natural spoken prose, describing mathematical notation in words: Bernoulli distribution. If X is distributed according to a Bernoulli distribution with parameter p, then the probability that X equals one is p, and the probability that X equals zero is one minus p. The expected value of X is p, and the variance of X is p times the quantity one minus p. Binomial distribution. If X is equal to the sum from i equals one to n of B sub i, where each B sub i is independently and identically distributed according to a Bernoulli distribution with parameter p, then X is distributed according to a Binomial distribution with parameters n and p. The probability that X equals k is given by n choose k, multiplied by p to the power of k, multiplied by the quantity one minus p to the power of n minus k. Furthermore, the expected value of X is n times p, and the variance of X is n times p times the quantity one minus p. Geometric distribution. If X represents the number of trials until the first success, then the probability that X equals k is the quantity one minus p to the power of k minus one, multiplied by p, for k equal to one, two, and so on. With the expected value of X being one divided by p. This distribution is memoryless, meaning: The probability that X is greater than m plus n, given that X is greater than m, is equal to the probability that X is greater than n. Poisson distribution. If X is distributed according to a Poisson distribution with parameter lambda, then the probability that X equals k is e to the power of negative lambda, multiplied by lambda to the power of k, all divided by k factorial. The expected value of X equals the variance of X, and both are equal to lambda. Independent Poisson variables have an additive property: If X is distributed according to a Poisson distribution with parameter lambda, and Y is distributed according to a Poisson distribution with parameter mu, and X and Y are independent, then X plus Y is distributed according to a Poisson distribution with parameter lambda plus mu. Negative Binomial distribution. Let X represent the number of trials needed to obtain the r-th success, where the success probability is p. Then the probability that X equals k is given by k minus one choose r minus one, multiplied by p to the power of r, multiplied by the quantity one minus p to the power of k minus r, for k equal to r, r plus one, and so on. And the expected value of X is r divided by p, while the variance of X is r times the quantity one minus p, all divided by p squared. This distribution is equivalent to the sum of r independent geometric waiting times. Multinomial distribution. If the vector N one, N two, up to N k is distributed according to a Multinomial distribution with parameters n, and p one through p k, then the probability that N one equals n one, N two equals n two, and so on, up to N k equals n k, is equal to n factorial, divided by the product of n one factorial, n two factorial, up to n k factorial, all multiplied by the product from j equals one to k of p sub j to the power of n sub j. This holds for nonnegative counts n one through n k that sum to n.

5.2 Continuous families. Here is the passage rewritten for audio narration, with mathematical notation described in words: First, let's consider the Uniform distribution. If a random variable, X, follows a Uniform distribution with parameters a and b, its probability density function at any value x is equal to one, divided by the quantity b minus a, for x values between a and b, inclusive, and zero otherwise. The expected value of X, also known as its mean, is given by the sum of a and b, divided by two. Next, we have the Exponential distribution. If a random variable X follows an Exponential distribution with a rate parameter called lambda, its probability density function at x is equal to lambda, multiplied by the mathematical constant e raised to the power of negative lambda times x, for x values greater than or equal to zero, and zero otherwise. The expected value of X is one divided by lambda. The Exponential distribution is notable for being the continuous distribution that possesses the memoryless property. This property means that the probability of X being greater than the sum of s and t, given that X is already known to be greater than s, is equal to the probability that X is simply greater than t. Moving on to the Gamma distribution. For this distribution, we have a shape parameter, alpha, which must be strictly greater than zero, and a rate parameter, lambda, also strictly greater than zero. The probability density function of X at x is given by a fraction. The numerator is lambda raised to the power of alpha, multiplied by x raised to the power of alpha minus one, multiplied by e raised to the power of negative lambda times x. The denominator is the Gamma function of alpha. This entire expression applies for x values strictly greater than zero, and the function is zero otherwise. For the Gamma distribution, the expected value of X is alpha divided by lambda. And the variance of X is alpha divided by lambda squared. Finally, let's look at the Beta distribution. This distribution has two parameters, alpha and beta, both of which must be strictly greater than zero. The probability density function of X at x is a fraction. The numerator is x raised to the power of alpha minus one, multiplied by the quantity one minus x raised to the power of beta minus one. The denominator is the Beta function of alpha and beta. This function applies for x values strictly between zero and one, and is zero otherwise. For the Beta distribution, the expected value of X is alpha divided by the sum of alpha and beta.
