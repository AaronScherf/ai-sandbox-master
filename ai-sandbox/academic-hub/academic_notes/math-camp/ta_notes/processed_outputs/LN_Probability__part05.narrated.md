The rigorous hierarchy of almost-sure, probability, L-P, and distributional convergence follows Klenke, Durrett, and Billingsley. Hansen and van der Vaart motivate the stochastic-order notation and asymptotic manipulations used later. 7.1 Four notions of convergence Let X sub n and X be random variables. Definition 7.1 — Almost-sure convergence We write that X sub n converges almost surely to X, if the probability that, for omega, X sub n of omega converges to X of omega, equals one. Definition 7.2 — Convergence in probability We write that X sub n converges in probability to X, if for every epsilon greater than zero, the probability that the absolute value of the difference between X sub n and X is greater than epsilon, converges to zero. Definition 7.3 — L-P convergence For P greater than or equal to one, we write that X sub n converges in L-P to X, if the expected value of the absolute value of the difference between X sub n and X, raised to the power p, converges to zero. Definition 7.4 — Convergence in distribution We write that X sub n converges in distribution to X, if the cumulative distribution function of X sub n, evaluated at x, converges to the cumulative distribution function of X, evaluated at x, at every continuity point x of F sub X. The main implication structure is as follows: X sub n converges almost surely to X, implies X sub n converges in probability to X, which in turn implies X sub n converges in distribution to X. And, X sub n converges in L-P to X, implies X sub n converges in probability to X. The reverse arrows fail in general. Proof To see that L-P convergence implies convergence in probability, we apply Markov's inequality. The probability that the absolute value of the difference between X sub n and X is greater than epsilon, equals the probability that the absolute value of the difference between X sub n and X, raised to the power p, is greater than epsilon raised to the power p. This is less than or equal to the expected value of the absolute value of the difference between X sub n and X, raised to the power p, all divided by epsilon raised to the power p, which converges to zero. Proposition 7.5 — Almost sure convergence implies convergence in probability If the sequence X sub n converges almost surely to X, then X sub n converges in probability to X. Proof. Fix epsilon, a positive number, and define A sub N as the union, for all n greater than or equal to N, of the set of outcomes where the absolute difference between X sub n and X is greater than epsilon. Then the sequence of sets A sub N is decreasing and converges to A, where A is a subset of the set of outcomes where X sub n does not converge to X. Almost-sure convergence implies that the probability of A is zero. By continuity from above, the probability of A sub N converges to zero. Since the probability that the absolute difference between X sub N and X is greater than epsilon is less than or equal to the probability of A sub N, convergence in probability follows. Proposition 7.6: Convergence in probability implies convergence in distribution. If the sequence X sub n converges in probability to X, then X sub n converges in distribution to X. A convenient proof uses the following inequalities, which hold for every epsilon greater than zero: The probability that X sub n is less than or equal to x is less than or equal to the probability that X is less than or equal to x plus epsilon, plus the probability that the absolute difference between X sub n and X is greater than epsilon. And the probability that X sub n is less than or equal to x is greater than or equal to the probability that X is less than or equal to x minus epsilon, minus the probability that the absolute difference between X sub n and X is greater than epsilon. At continuity points of the cumulative distribution function of X, first let n go to infinity, then let epsilon decrease to zero. Remark 7.7: Rigorous layer: Subsequence characterization. A useful theorem states that X sub n converges in probability to X if and only if every subsequence, X sub n sub k, contains a further subsequence, X sub n sub k sub j, such that X sub n sub k sub j converges almost surely to X. Convergence in probability is therefore exactly the mode of convergence where every subsequence has an almost-surely convergent refinement. 7.2 A counterexample to probability implying almost sure convergence. Let Omega be the closed interval from zero to one with Lebesgue probability measure, and let X sub n be indicator random variables for intervals that sweep repeatedly across the interval from zero to one, with their lengths tending to zero. Then the probability that X sub n equals one converges to zero, so X sub n converges in probability to zero. However, one can arrange for every omega, or every point in the sample space, to belong to infinitely many of these intervals, so X sub n of omega does not converge to zero. This illustrates that convergence in probability controls each n separately, while almost-sure convergence controls the whole path of the sequence. 7.3 Subsequence characterization of convergence in probability. A useful bridge between convergence in probability and almost-sure convergence is the following proposition. Proposition 7.8: Almost-sure subsequences.
