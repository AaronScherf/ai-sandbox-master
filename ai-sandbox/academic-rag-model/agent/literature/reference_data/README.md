# Reference data

`countries.yaml` is the ISO 3166-1 alpha-2 code and name list, generated by `make_countries.py` from the `tzdata`
package's `iso3166.tab` (run once and commit the output).
`country_subregions.yaml` maps country codes to UN M49 subregions for gap analysis adjacency; it contains no names,
and AQ and UM have no subregion.
